ESP32 DevKitC
- 32-bit Xtensa dual-core @ 240 MHz
- Wi-Fi IEEE 802.11b/g/n 2.4 GHz
- Bluetooth 4.2 BR/EDR and BLE
- 520 KB SRAM (16 KB for cache)
- 448 KB ROM
- 34 GPIOs, 4x SPI, 3x UART, 2x I2C
- 2x I2S, RMT, LED PWM, 1 host SD/eMMC/SDIO
- 1 slave SDIO/SPI, TWAI, 12-bit ADC, Ethernet

LEGENDA DAS FUNCOES
- GPIOX | GPIO Input Only (somente entrada)
- GPIOX | GPIO Input and Output (entrada e saida)
- DAC_X | Digital-to-Analog Converter
- DEBUG | JTAG for Debugging
- FLASH | External Flash Memory (SPI)
- ADCX_CH | Analog-to-Digital Converter
- TOUCHX | Touch Sensor Input Channel
- OTHER | Other Related Functions
- SERIAL | Serial for Debug/Programming
- ARDUINO | Arduino Related Functions
- STRAP | Strapping Pin Functions
- RTC | RTC Power Domain (VDD3P3_RTC)
- GND | Ground (terra)
- PWD | Power Rails (3V3 e 5V)
- ! | Pino compartilhado com a memoria Flash SPI. Nao pode ser usado como GPIO comum.


GPIO STATE
- WPU | Weak Pull-up (interno)
- WPD | Weak Pull-down (interno)
- PU | Pull-up (externo)
- IE | Input Enable (habilitado apos reset)
- ID | Input Disabled (desabilitado apos reset)
- OE | Output Enable (habilitado apos reset)
- OD | Output Disabled (desabilitado apos reset)


COMPONENTES DA PLACA
- ESPRESSIF | Fabricante
- ESP32-WROOM | Modulo ESP32
- CP2102 | Conversor USB para serial
- EN | Habilitacao/Reset
- BOOT | Botao de inicializacao
- 3V3 | Alimentacao de 3,3 V
- 5V0 | Alimentacao de 5 V
- GND | Terra


OBSERVACAO
- Os GPIOs 6 a 11 sao normalmente utilizados pela memoria Flash interna do modulo ESP32-WROOM e nao devem ser usados como GPIOs de uso geral.
